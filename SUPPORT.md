# Support

ERD Go is maintained as an open-source project. The best place to get help is GitHub Issues, where answers remain searchable for other users.

## Before opening an issue

1. Try the latest version at [erdgo.com](https://erdgo.com/).
2. Search [existing issues](https://github.com/tanlee102/ErdGo/issues).
3. Remove private data and reduce the SQL to a small, synthetic example.
4. Record the SQL dialect, browser, operating system, and exact steps that reproduce the problem.

[Open a bug report](https://github.com/tanlee102/ErdGo/issues/new?template=bug_report.yml) or [request a feature](https://github.com/tanlee102/ErdGo/issues/new?template=feature_request.yml).

Security problems must be reported privately according to the [security policy](SECURITY.md). Never post credentials, API keys, private schemas, or production data in an issue.
